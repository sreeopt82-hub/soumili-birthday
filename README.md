# Soumili Birthday Website ❤️

A romantic, interactive birthday microsite built as a lightweight static site.

## Deploy to Vercel

### Fastest way
1. Upload this project folder to a GitHub repository.
2. Import the repository into Vercel.
3. Vercel will detect it as a static site. No build command is required.
4. Deploy.

### Vercel CLI
```bash
npm i -g vercel
vercel
```

Or, from the project directory:
```bash
npx vercel
```

## Run locally

Because this is a static site, you can simply open `index.html`. For a local server:

```bash
python -m http.server 8080
```

Then visit `http://localhost:8080`.

## What's included

- Animated birthday landing page
- Interactive story/typewriter section
- Clickable relationship timeline
- Photo lightbox
- Memory shuffle interaction
- Floating hearts and celebration effects
- Final birthday letter
- Responsive mobile layout
- Reduced-motion accessibility support
- No backend, database, API keys, or environment variables required

The supplied images are already included in `assets/`.
